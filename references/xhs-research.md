常见打卡点：
- 月亮湾
- 点将台
- 金花紫卉
- 克勒涌珠（天鹅）
- 松树头
- 网红 S 湾
- 灯塔
- 西海草原

推荐游玩顺序：
- 常规环湖版：东门入园 -> 月亮湾 -> 点将台 -> 金花紫卉 -> 克勒涌珠 -> 松树头 -> 南门出 -> 果子沟大桥
- 日落追光版：傍晚从东门进，按光线和风力优先去 S 湾 / 松树头 / 灯塔附近，不再平均分时间给全部停靠点

适合拍照时间：
- 松树头日出：8:00 前后
- 松树头暖光 / 大桥剪影：18:00-20:00
- 半夏笔记认为：最佳日落在网红 S 湾，最佳日出在灯塔；清晨湖水色彩不如傍晚浓
- 另有笔记记录 22:15 左右仍有粉调蓝调日落氛围，但风大、需控制返程

建议停留：
- 松树头初级平台：10-15 分钟
- 松树头半山腰草坪：往返约 1.5 小时
- 松树头登顶：往返约 2.5-3 小时
- 普通环湖停车点：单点 15-25 分钟，避免反复上下车拖慢全线

避坑提醒：
- 时间紧不建议专门靠区间车去松树头
- 松树头左岔更容易看到果子沟大桥，右岔更偏纯湖景人像
- 栈道后段偏陡且可能湿滑，下山防滑鞋很重要
- 克勒涌珠附近露营和停车管理更严格，不能把“网传扎营点”当成稳定玩法

需要继续核实：
- 自驾票、门票、区间车的最新拆分规则
- 学生票是否线上购买、是否需要现场验学生证
- 环湖区间车首末班和固定停靠站是否有调整

- 全域玩法：6-8 小时

- 万纳服务区不要盲目往更深处开，公开笔记明确提到错过 1 号 / 2 号停车场后，可能一路开到出口再重进
- “最晚区间车时间”在公开笔记里说法不一致，不能只凭工作人员一句话就把返程压到最后
- 如果下午才到，别再贪鲜花台、滑草、骑马、猎鹰台全刷

需要继续核实：
- 自驾票究竟能开到哪里，是否只是到指定停车区后继续换乘
- 2026 年最新区间车末班、草原区与阔克苏线路分流规则
- 学生票和项目票（滑草、骑马）是否有现场优惠

来源：

常见打卡点：
- 游客中心
- 空中草原：天界台、天牧台、游牧人家、网红桥、溪流小桥、小山坡
- 雪莲谷
- 盘龙谷道：塔吾萨尼、乌孙古迹、依提根赛、蛟龙出海、卧牛岗、森林公园

推荐游玩顺序：
- 只有一天时，先保空中草原
- 如果还想补第二条线，公开笔记更偏向“盘龙谷道优先于河谷草原”，因为盘龙谷道前半段与河谷草原有重合
- 游牧人家是空中草原精华位，不建议蜻蜓点水

适合拍照时间：
- 当前可读笔记没有给出非常精确的黄金时间，但都强调空中草原是主线、晴天通透度更高
- 游牧人家沿溪流往里走，比网红桥排队点更容易出片

建议停留：
- 游牧人家：至少 4 小时
- 沿溪流走到上游冰块发源处：约 40 分钟徒步量级，需量力而行
- 雪莲谷：若决定去，直接走景区车方案更稳

避坑提醒：
- 网红桥排队重，不值得把主线时间耗掉
- 不要把三条线都写进同一天
- 缆车可能因天气或检修停运，不能把它当刚性环节

需要继续核实：
- 自驾预约是否必须提前抢、当天是否有临时放行
- 缆车当天运营情况
- 河谷草原 / 盘龙谷道的最新重叠与回程换乘规则
