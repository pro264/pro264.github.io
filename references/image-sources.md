## 当前建议

1. 先不要把小红书 / 大众点评图片搬进项目。
2. 若你手头有自己拍的、朋友授权的、或能明确确认许可的图片，优先手动放入 `assets/scenic/`。
3. 如果下一阶段要我正式替换 hero 图，最需要你手动补图的优先顺序是：
   - 赛里木湖
   - 喀拉峻
   - 那拉提
   - 巴音布鲁克
   - 天山神秘大峡谷
   - 博斯腾湖
4. 城市类图（乌鲁木齐 / 伊宁 / 库尔勒）可以相对容易地从开放图库里补，但核心景区最好还是用你认可的实景图。
