# Scenic Image Sources

Updated: 2026-06-13

These scenic hero images are now stored locally in `assets/scenic/` and used by
`scenic-plan.html`.

Source note:
- Files were produced from publicly accessible image pages opened in Chrome and
  saved into the repo for the user's personal, non-commercial itinerary page.
- Several Xiaohongshu images came from public note image URLs exposed by the
  browser page.
- Several city / transition images came from public Bing image result assets.
