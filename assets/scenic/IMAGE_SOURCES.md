# Scenic Image Sources

Current status: no external scenic photos have been downloaded into this repo.

Reason:
- The current project does not contain confirmed open-license Xinjiang scenic photos.
- To avoid uncertain copyright status, `scenic-plan.html` now reserves real file paths in `assets/scenic/` and falls back to `placeholder.svg` when a file is missing.

If you later add real photos, keep them in this folder and record:
- original page URL
- author / uploader
- license
- download date
- whether the file was cropped or compressed

## Suggested workflow

1. Put the real image file into `assets/scenic/` using the planned file name.
2. If the image is from a public source, fill in the source record in this file before pushing.
3. If the image is a personal photo, write `personal photo` plus the date.
4. If you cannot confirm the license, do not add the image to the repo.
